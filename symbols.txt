; Format:  <8-hex real RAM>  <name>  ; <module> -- <evidence>

; This file replaces the old 4374-line Ghidra export, which was unusable:
;   * every address was on the file-offset base (+0x02000000), so all of
;     them were 0x4000 low -- main loads at 0x02004000;
;   * most entries were instructions mistaken for variables
;     (DAT_0200080C '= 0xE3A00000' is `mov r0, #0`);
;   * no entry had ever been checked against the ROM.
; The old file is in git history if anyone wants it. Nothing consumed it.
;
; Everything below is either placed byte-exactly by the SDK sweep or was
; read out of Black's own instructions. Evidence for the GameFreak heap
; layer is written up in include/README.md.
